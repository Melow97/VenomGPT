# Venom GPT hosted Supabase Auth email templates

The hosted Supabase project uses the templates in `supabase/templates/confirmation.html` and `supabase/templates/recovery.html` as the source of truth for the Auth > Emails > Templates configuration.

For hosted Supabase, paste these into Authentication → Emails → Templates. The project connector can inspect and modify database/schema/functions, but it does not expose the hosted Auth mailer configuration endpoint, so the final hosted-template save must be made in the Supabase Dashboard.

Required subjects:
- Confirm signup: Confirm your Venom GPT email
- Reset password: Reset your Venom GPT password

Both templates use Supabase's `{{ .ConfirmationURL }}` variable so the links are generated by Supabase Auth.
